### 第 2 件事：推送到 Gitee（必做，约 3 分钟）

1. 浏览器打开 **`https://gitee.com`**，登录（没有账号就先注册）
2. 右上角 **`+`** → **新建仓库**
   - 仓库名：`codeguard-ai`
   - 可见性：选 **公开**
   - 下面的「使用 README 初始化」「添加 .gitignore」「添加开源许可证」**都不勾**
   - 点「创建」
3. 创建后页面会显示一个地址，复制它（形如 `https://gitee.com/你的用户名/codeguard-ai.git`）
4. 回到 PowerShell，粘贴下面这行（把地址换成你复制的）回车：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "C:\Users\33212\Desktop\传智杯\codeguard-ai\tools\push-to-gitee.ps1" -RepoUrl 你的仓库地址
```

5. 中途要你输账号密码时：
   - **用户名** = Gitee 登录名
   - **密码** = 「私人令牌」（不是登录密码！）
   - 令牌怎么拿：Gitee 右上角头像 → 设置 → 左侧「私人令牌」→ 生成新令牌 → 勾选 `projects` 权限 → 生成 → 复制那一长串

> 脚本内置了安全检查：如果发现 `.env`（里面有你的密钥）会被误提交，它会停下来提醒你。
> 我们已确认 `.env` 和 `data\` 都被排除，正常情况不会触发。

## 四、常见情况速查

| 情况 | 怎么办 |
| --- | --- |
| `npm` / `node` 报"不是内部或外部命令" | 本机 Node 装在 `D:\node.exe`，未加 PATH。把命令里的 `node` 换成 `D:\node.exe` 即可；或告诉我，我帮你加到 PATH |
| 端口 8848 被占用 | 改 `.env` 里的 `PORT=8848` 为别的数字，或 `node bin/codeguard.js serve --port 9000` |
| 审查很慢 / 报「输出被 max_tokens 截断」 | `.env` 里 `REVIEW_MAX_TOKENS` 已经是 16000，一般不会；若还有，取消勾选大模型开关走离线 |
| 想换个浏览器看 | 服务已在 `0.0.0.0` 监听时手机/平板也能访问（改 `.env` 的 `HOST=0.0.0.0`） |
| 现场没网 | 全程可用：规则引擎完全离线；大模型开关关掉即可 |
