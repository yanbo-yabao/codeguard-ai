# 评分标准对齐说明

> 本文把作品能力与赛事评分维度逐项对齐，每条给出**验证入口**（文件 / 接口 / 命令），评委可原样复核。
> 产品定位：**AI 编程学习助手**——提问解题 → 变式练习 → 运行判题 → 逐行调试的完整学习闭环。

## 一、AI 技术深度（35%）

| 考察点 | 权重 | 本作品的落点 | 验证入口 |
| --- | ---: | --- | --- |
| 大模型集成质量 | 8% | OpenAI 兼容协议统一适配 **12 家供应商**（网页一键切换）；任务化专家提示词（诊断/解题/出题三套契约，严格 JSON 输出）；温度按任务区分、三级容错解析、指数退避重试、思维链截断诊断 | `src/agents/prompt-templates.js`、`src/agents/llm-client.js` |
| Agent / 工作流设计 | 8% | 解题补全双阶段流水线（RAG 检索 → 生成 → 语法自检 → 安全复检）；错误修复双引擎交叉印证（确定性语法引擎 + AI 诊断，同行命中记印证）；「学→练→调」多步工作流（解题 → 变式出题 → 自动判题 → 逐行调试）；三级降级（真实 LLM → 离线模板库 → 演示占位，来源全程标注） | `src/services/completion-service.js`、`web/assets/app.js` |
| RAG 技术应用 | 6% | 内置 16 条 CWE/OWASP 对齐知识库 + 中文二元组四路信号确定性检索（阈值宁缺毋滥）；命中注入提示词约束生成（修复模式、安全最佳实践）；命中随结果展示可解释 | `src/rag/`、`src/services/completion-service.js` |
| 多模态能力 | 5% | **图像输入已实现**：题目截图/报错截图/手写笔记随文字问题一同发给视觉大模型（Kimi K3、GLM-4V 等），图文同题融合推理；图片格式/体积校验；不支持视觉时明确提示，绝不假装读过 | `web/index.html` 图片上传区、`src/agents/prompt-templates.js`（image_url 消息） |
| AI 安全与可控 | 4% | 产出代码安全复检（生成代码回扫安全规则）+ 语法自检；全链路降级与 warnings 说明；API 密钥脱敏存储；结果来源标注（真实 AI / 模板库 / 演示）杜绝冒充 | `src/services/completion-service.js`、`test/quiz-image.test.js` |
| MCP / 工具集成 | 4% | MCP stdio 服务器暴露 5 个工具（complete_code / fix_code / quiz_code / run_code / list_rules，含 JSON Schema），Claude / Cherry Studio 等外部 AI 可直接调用；`run_code` 让外部 AI 真实执行与判题代码 | `src/mcp/server.js`、`docs/MCP接入说明.md` |

## 二、创新性（25%）

| 亮点 | 说明 | 验证入口 |
| --- | --- | --- |
| 学习闭环而非单点工具 | 解题（多模态）→ AI 微改变式题 → OJ 式自动判题 → 逐行调试，四步连成完整学习路径 | Web 三工作模式 |
| 判题确定性可信赖 | 判题是输出精确比对（确定性），不经过大模型，无法被"说服"；参考答案可自证（AI 出的题用 AI 出的解验证） | `src/runners/runner-service.js` judge |

| 逐行调试可视化 | 行执行次数（循环可视化）+ 变量快照：JS 行探针 / Python sys.settrace 双实现 | `test/runner-service.test.js` |
| 诚实的 AI | 每个结果标注来源（真实 AI / 内置模板库 / 演示占位），离线能力边界写进界面与文档 | README「能力边界」表 |

## 三、前端工程质量（10%）

- 原生 HTML/CSS/JS，无构建步骤、无框架依赖，可维护可扩展
- 三工作模式结果**互相独立**（有回归测试锁死）；图片上传（点击/拖拽/预览/移除）；判题结果表、调试轨迹表
- 新手引导弹窗（首次自动展示）、快捷键（Ctrl+Enter）、Toast 反馈、响应式布局
- 验证：`test/mode-isolation.test.js`、`test/api.test.js`（静态页面）

## 四、实用性（10%）

- **判题/调试/静态检查离线可用**（不填密钥照常工作）；AI 能力一键接入 12 家供应商
- 服务端真实执行：独立子进程 + 超时熔断（30 秒上限）+ 输出截断，安全边界清晰；支持 **C / C++ / Java / JavaScript / Python** 五种语言（编译型语言判题只编译一次，编译报错定位到行）；语言下拉框自动探测本机工具链，只列真能跑的
- CLI 与 Web 双入口，REST API 13 个接口，MCP 5 个工具
- 验证：`npm test`（148 用例全绿）、`npm run doctor`

## 五、用户体验（10%）

- 界面语言全中文、大白话；「演示模式 vs 真实 AI」的边界在使用说明里写明
- 错误可行动：判题失败显示「期望 vs 实际」，报错定位到行，调试轨迹按行聚合
- 降级提示不藏错：每条 warnings 都说明发生了什么、影响什么
- 验证：`web/index.html` 使用说明弹窗、`build/_ui_main.png` 截图

## 六、社会价值（10%）

- 面向编程学习者：讲题（不只给答案，讲思路）、出练（变式题防死记）、排障（调试可视化）
- 降低优质编程辅导门槛：不联网也有模板库与真实执行能力，欠发达地区一台电脑即可使用
- 培养工程习惯：判题用例思维、看报错定位、逐行跟踪排错
