          使用说明 · 跟着点就行，不需要懂技术
          
      
    
          

    
          
      本工具在你自己的电脑上运行。下面是三个功能，各三步。
    
          

    
          
      
          ① 问问题、拍题目，AI 给你讲解 + 代码（AI 解题与补全）
          
      
            
        
          1. 在「问题 / 需求」框里写下你的问题，比如 这道题怎么做？…；
          如果题目是截图或手写照片，点下面的图片区上传（AI 能看图解题）
            2. 
        
          2. 点「开始解题 / 补全」，等 10~60 秒
            3. 
        
          3. 结果里有两样东西：解题讲解（思路 + 每一步为什么这么做）和
          完整代码（点「复制代码」拿走）
            4. 
      
          
      
          💡 学完想练？点结果里的「出题测试我」按钮，AI 会按这道题出一道变式题考你。
          
    
          

    
          
      
          ② 做变式题、真实运行判题（学完就练）
          
      
            
        
          1. 在解题结果里点「出题测试我」，变式题（题面 + 提示 + 参考答案）直接出现在下方
            2. 
        
          2. 在「你的解答」框里写代码（程序从标准输入读入、标准输出写出，和 OJ 一样）
            3. 
        
          3. 点「自动判题」：系统会用题目自带的多组测试用例真实运行你的代码，逐组告诉你
          通过 / 不通过，不通过的显示「期望输出 vs 实际输出」
            4. 
      
          
      
          💡 只想跑一下代码？点「运行」；想看代码一步步怎么执行的？点「调试运行」。
          
      
          💡 不问问题也想跑代码？切到顶部「代码测试」标签，粘贴任意代码即可运行看输出。
          
    
          

    
          
      
          ③ 调试运行：看代码一行一行怎么跑的
          
      
            
        
          1. 点「调试运行」后，结果里有一张调试轨迹表：
          每一行代码执行了几次（循环体能看到执行多次）、每次执行时变量的值
            2. 
        
          2. 程序报错时，「错误信息」里会显示第几行出错和原因
            3. 
      
          
      
          💡 用它排查「死循环」「变量值不对」这类问题最直观。
          
    
          

    
          
      
          ④ 错误检查与修复：把有错的代码改对
          
      
            
        
          1. 点顶部「错误检查与修复」标签，把有错误的代码贴进大框
            2. 
        
          2. 点「开始检查与修复」
            3. 
        
          3. 结果里有每条错误的修改方法（改哪行、怎么改）和修复后的完整代码
            4. 
      
          
    
          

    
          
      
          ⑤ 重要：什么是"演示模式"，什么是"真实 AI"
          
      
            
        
          • 没填 API Key（默认状态）：「运行 / 判题 / 调试」是真实执行的（离线可用），
          「错误检查与修复」的静态检查也是真实的；但解题讲解和出题是演示占位，只用于看流程
            • 
        
          • 想用真实 AI：点右上角「⚙ 设置大模型」→ 供应商下拉框选一家 →
          粘贴你自己的 API Key → 点「测试连接」→ 点「保存并生效」。保存后立即生效，不用重启
            • 
        
          • 拍图提问需要支持看图的模型（如 Kimi K3、GLM-4V 系列）；普通模型只能文字提问
            • 
        
          • API Key 需要自己申请，密钥只保存在你自己的电脑上，不会进入代码库
            • 
      
          
    
          

    
          
      
          ⑥ 常见问题
          
      
            
        
          • 会不会很慢？运行 / 判题 / 调试 1~5 秒出结果；AI 解题 10~60 秒
            • 
        
          • 我的代码安全吗？运行在本机独立进程里，超时 30 秒自动终止；
          只有开启大模型时，代码才会发送给你自己配置的 AI 服务
            • 
        
          • 快捷键：按 Ctrl + Enter 可以快速提交当前任务
            • 
        
          • 点错了 / 想重来：点「清空」按钮即可重新开始
